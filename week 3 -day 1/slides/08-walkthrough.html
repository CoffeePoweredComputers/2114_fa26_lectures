Which contains() Implementation Cannot Be Used?

A multiple-choice question: four candidate implementations of contains(T anEntry) for an ArrayBag, labeled A through D, arranged as code cards. Option A walks the array with a while loop and a found flag. Option D walks the array with a while loop bounded by i less-than-or-equal-to numberOfEntries instead of i less-than numberOfEntries. Option B returns whether getIndexOf is greater than minus one. Option C returns whether getFrequencyOf is greater than zero. A prompt at the bottom asks which one cannot be used, with quick-pick chips A through D.

  1. Option A

    1. public boolean contains(T anEntry) {
    2. boolean found = false;
    3. int i = 0;
    4.  
    5. while (!found && (i < numberOfEntries)) {
    6. if (anEntry.equals(contents[i])) {
    7. found = true;
    8. }
    9. i++;
    10. }
    11. return found;
    12. }

  2. Option D

    1. public boolean contains(T anEntry) {
    2. int i = 0;
    3.  
    4. while (i <= numberOfEntries) {
    5. if (anEntry.equals(contents[i])) {
    6. return true;
    7. }
    8. i++;
    9. }
    10. return false;
    11. }

  3. Option B

    1. public boolean contains(T anEntry) {
    2. return getIndexOf(anEntry) > -1;
    3. }

  4. Option C

    1. public boolean contains(T anEntry) {
    2. return getFrequencyOf(anEntry) > 0;
    3. }

Which one is incorrect?

  • A
  • B
  • C
  • D
Answer: D — its bound, i <= numberOfEntries instead of i < numberOfEntries, lets i reach one past the last valid index, so contents[numberOfEntries] throws ArrayIndexOutOfBoundsException whenever the entry being searched for is not in the bag. A is a correct, if verbose, linear scan with a found flag. B correctly reuses getIndexOf: any non-negative index means a match turned up. C correctly reuses getFrequencyOf: any count greater than zero means the entry is present. D is the only one that cannot be used as written. Options are ordered A, D, B, C on the grid so the two long panels share a row and the two short ones share the other — read by the letter in each card's bar, not by position.
