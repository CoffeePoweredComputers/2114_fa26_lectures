Warm-up: references

Employee e1 = new Employee();
Employee e2 = new Employee();
e1.setID(123);
e2.setID(456);
e1 = e2;

Q1

Assign e1 to an employee object with ID 555 — without changing the value referenced by e2.

Q2

Make the IDs of both e1 and e2 equal 789. This can be done in one line.

The punchline: after e1 = e2; both names alias the same object. Ported from legacy CodeWorkout Q5 and Q6, worded platform-agnostically.
