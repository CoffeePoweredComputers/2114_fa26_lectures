P1 · Learning to Scope

A small OO Java app of your choosing — task tracker, vending machine, flashcard quiz, text adventure. Multiple classes with single responsibilities, GitHub, and exception handling that survives bad input gracefully.

  1. Scope — one page: what, MVP, stretch, bad input, unknowns
  2. Spec — 3–5 pages: classes, data, contracts, validation map, test plan
  3. Final — minimal build, JUnit tests, writeup, 3-minute lightning talk

You will get the scope wrong the first time. That is expected — and cheap to fix at the scope stage.
